# PromptLibrary Manager

Расширение для Chromium-браузеров для ведения персональной библиотеки промтов (prompts) и быстрого доступа к ним на поддерживаемых сайтах.

### Возможности
- Создание и управление группами промтов
- Добавление, редактирование и удаление промтов
- Быстрое копирование текста промта
- Импорт/экспорт всей библиотеки в JSON
- Встроенное всплывающее меню на разрешённых сайтах (позиция настраивается)

## Установка (режим разработчика)
Расширение использует Manifest V3 (service worker). Поддерживаются Chrome/Edge/Brave и другие Chromium-браузеры. Firefox в текущей конфигурации не поддерживается.

1. Клонируйте репозиторий
2. Откройте в браузере страницу расширений: `chrome://extensions/`
3. Включите «Режим разработчика»
4. Нажмите «Загрузить распакованное» и укажите корень проекта

## Использование
- Откройте popup расширения (иконка на панели):
  - Создавайте группы и промты, редактируйте и удаляйте
  - Импортируйте/экспортируйте данные в JSON
- На сайтах из списка `allowList` появится плавающая кнопка. Нажмите её, чтобы открыть меню «Prompt Library» и быстро копировать промты.

## Конфигурация
Основная конфигурация — в `src/config.js`.

```javascript
const CONFIG = {
  allowList: [
    "https://chat.openai.com/*",
    "https://claude.ai/*"
  ],
  menuPosition: "bottom-right" // top-right | top-left | bottom-left | bottom-right
};

function matchesAllowList(url) { /* ... */ }
export { CONFIG, matchesAllowList };
```

- **allowList**: список URL‑шаблонов, где будет активироваться плавающее меню.
- **menuPosition**: позиция меню относительно кнопки‑триггера.

## Права и причины
См. `manifest.json`:
- `storage`: хранение библиотек промтов
- `activeTab`, `scripting`: запуск скриптов для модалок/копирования
- `host_permissions: <all_urls>`: технически для всех сайтов; реальная активация контролируется `allowList` внутри контент‑скрипта

## Структура проекта
- `src/`
  - `background.js` — обработка сообщений, показ модалок от фона, обновление меню
  - `content.mjs` — плавающее меню на страницах, работа с `allowList`
  - `config.js` — конфигурация (`allowList`, позиция меню)
  - `popup/` — UI управления библиотекой (группы/промты, импорт/экспорт)
  - `utils/` — утилиты хранения и экспорта
- `icons/` — иконки
- `manifest.json` — манифест MV3

## Формат данных (экспорт)
```json
{
  "groups": [
    {
      "id": "uuid",
      "name": "Group name",
      "prompts": [
        { "id": "uuid", "title": "Title", "content": "Prompt text" }
      ]
    }
  ]
}
```

## Разработка
Сборка не требуется. После правок:
- Перезагрузите расширение в `chrome://extensions/`
- Обновите страницу сайта, где используется меню

Полезные файлы:
- Контент‑скрипт: `src/content.mjs`
- Popup (UI): `src/popup/index.html`, `src/popup/script.js`, `src/popup/style.css`
- Хранилище/экспорт: `src/utils/storage.js`, `src/utils/export.js`

## Устранение неполадок
- Меню не появляется: проверьте, совпадает ли URL с шаблоном в `allowList`
- Копирование не работает: вкладка должна быть активна; проверьте разрешение к буферу обмена
- Видите устаревшие данные: импортируйте актуальный JSON или очистите хранилище расширения

## Дисклеймер
Проект ориентирован на Chromium‑браузеры (Manifest V3). Поддержка Firefox потребует адаптации (другой фон/permissions/скрипты).
